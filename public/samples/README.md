# DitherIT color study

`ditherit-study.png` is original procedural artwork created for DitherIT. It contains a grayscale ramp, a shaded color sphere, deterministic grain, fine diagonal edges and RGB color swatches. Dimensions: 1200 × 800; opaque RGBA PNG.

Provenance: generated entirely from numeric functions in `scripts/generate-sample.mjs`; no photographs, third-party imagery, fonts or private metadata are included. Regenerate from the repository root with `node scripts/generate-sample.mjs`.
